---
title: Reverse Proxy Setup
description: Configure nginx or Caddy to serve Fabricator securely behind a reverse proxy.
---

Fabricator has no built-in authentication layer documented here. If the host is reachable from untrusted networks, put it behind a trusted reverse proxy, access control layer, VPN, or firewall.

## Recommended binding

Keep Fabricator on loopback when the proxy runs on the same host:

```ini
HOST=127.0.0.1
PORT=5000
```

Then restart:

```bash
sudo systemctl restart fabricator
```

The packaged installer writes `HOST=0.0.0.0` for easy first access. Change it before exposing the server broadly.

## nginx example

```nginx
server {
    listen 80;
    server_name fabricator.example.com;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

Add TLS with Certbot, your platform's certificate automation, or a provider such as Cloudflare.

## Caddy example

```text
fabricator.example.com {
    reverse_proxy 127.0.0.1:5000
}
```

Caddy automatically provisions TLS when DNS points to the host.

## Security checklist

- Restrict access with VPN, SSO, basic auth, or firewall rules.
- Use HTTPS for remote browser access.
- Do not set `CORS_ORIGINS=*`; Fabricator rejects it.
- Keep the Minecraft server port separate from the Fabricator dashboard port.
- Review `/etc/sudoers.d/fabricator-self-update`; it should only allow the bundled update wrapper.
