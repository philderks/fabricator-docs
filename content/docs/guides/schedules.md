title: Schedules
description: Run console commands, restarts and other steps on a timer. 
---

The Schedules page allows you to set up server starts, stops, restarts, and custom commands

## What the page shows
- Upcoming schedules.
- When it will run.
- The last time it ran.
- The steps/commands it will execute.
- An enable/disable switch.

## Creating a schedule

The new schedule page allows you to make multiple steps to be executed every few minutes, every day at a time or you can use a cron expression to do advanced scheduling.

You can have multiple steps to be executed on a delay if you would like.
